# 🎵 SoundFlow

A responsive music player built using HTML, CSS, and JavaScript.

## Features

- Play, Pause, and Stop audio
- Next and Previous track controls
- Volume control and mute option
- Audio progress tracking
- Dynamic playlist generation
- Active song highlighting
- Move selected song to the top of the playlist
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)


## How to Run

1. Clone the repository

```bash
https://github.com/OsamaSobhy2006/SoundFlow.git
```

2. Open `index.html` in your browser
